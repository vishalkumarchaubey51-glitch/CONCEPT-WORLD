## 🔧 Manual Configuration Required (3 Easy Steps)

### **STEP 1: Configure EmailJS for Contact Form** ⭐ PRIORITY

**Why:** Without this, contact form won't send emails

**How:**
1. Visit [emailjs.com](https://www.emailjs.com)
2. Sign up (free account)
3. Connect Gmail account
4. Create email template
5. Copy: Service ID, Template ID, Public Key

**Where to put it:**
- **File:** `assets/js/contact-form.js` (Line 11)
  ```javascript
  emailjs.init({
      publicKey: "YOUR_PUBLIC_KEY_HERE"  // 👈 PASTE HERE
  });
  ```

- **File:** `contact.html` (Line ~335)
  ```javascript
  emailjs.send('YOUR_SERVICE_ID', 'YOUR_TEMPLATE_ID', templateParams)
                  // 👆 PASTE BOTH HERE
  ```

## 🚀 Deployment Instructions

### **Option A: GitHub Pages (Recommended for developers)**
```bash
1. Create GitHub repository
2. Push all files: git push origin main
3. Settings > Pages > Deploy from branch > main
4. Your site: https://username.github.io/repo-name
```

### **Option B: Netlify (Recommended - easiest)**
```bash
1. Go to netlify.com
2. Click "Add new site" > "Deploy manually"
3. Drag & drop your project folder
4. Done! Site is live with URL like: quirky-name-12345.netlify.app
```

### **Option C: Vercel (Very fast)**
```bash
1. Go to vercel.com
2. Import GitHub repo or drag folder
3. Click Deploy
4. Site is live
```

### **Option D: InfinityFree (Traditional hosting)**
```bash
1. Create account at infinityfree.net
2. Create new website
3. Upload files via FTP/File Manager
4. Site goes live at provided domain
```

## 🆘 Troubleshooting

### **Problem:** Contact form not sending
**Solution:** 
1. Verify EmailJS Service ID and Template ID
2. Check browser console (F12) for errors
3. Verify sender email in EmailJS settings

### **Problem:** Images not loading
**Solution:**
1. Check image file paths in /image/ folder
2. Verify path in data/projects.json
3. Use browser DevTools to see 404 errors

### **Problem:** Navigation not showing
**Solution:**
1. Verify load-navbar.js is loading
2. Check for JavaScript errors (F12)
3. Clear browser cache (Ctrl+Shift+Delete)

### **Problem:** Styles look broken
**Solution:**
1. Hard refresh page (Ctrl+Shift+R)
2. Check CSS file paths
3. Verify Bootstrap CDN is loading
